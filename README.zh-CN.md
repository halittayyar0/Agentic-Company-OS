## 用来交办和跟进工作的空间

给智能体一项明确的任务，或安排一项按计划重复执行的职责。它可以使用你允许的工具、保存结果，并在缺少信息或需要批准时向你询问。你可以在同一个界面中跟踪进度、检查执行过程，也可以停止执行。

每次安装都是运行在你的电脑或服务器上的**单人私有工作空间**。模型提供商由你选择，访问凭据由你持有。公开网站用于引导安装；任务在你自己的工作空间中运行。

| 从一次性任务开始                   | 或安排一项日常职责                       |
| ---------------------------------- | ---------------------------------------- |
| 比较三款产品，并附上来源链接。     | 每天检查一个公开网页，记录有意义的变化。 |
| 检查 CSV 文件中的缺失值和重复值。  | 按计划审阅定期报告。                     |
| 审查代码仓库，提出经过测试的修改。 | 重复执行指定的检查清单，保留每轮结果。   |

这些是任务示例，不是对结果的保证。结果取决于模型、可用工具、权限以及你提供的信息。

## 快速开始

### 1. 选择安装方式

|                | 预构建容器安装包                                                                                                         | 从源代码原生安装                                                                   |
| -------------- | ------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------- |
| **适合**       | 直接使用预构建应用                                                                                                       | 直接处理源代码和主机工具                                                           |
| **准备条件**   | Node.js 24，以及运行 Linux 引擎并支持 Compose v2 的 Docker                                                               | Git、Node.js 24、项目固定版本的 pnpm、PostgreSQL；浏览器工具还需要 Chromium        |
| **应用构建**   | 自动下载固定版本的镜像                                                                                                   | 在你的电脑上构建                                                                   |
| **从这里开始** | [下载安装 ZIP](https://github.com/halittayyar0/Agentic-Company-OS/releases/latest/download/Agentic-Company-OS-setup.zip) | [原生安装指南](./docs/self-hosting.md#guided-installation-windows-linux-and-macos) |

容器安装包包含 PostgreSQL 和 Chromium，无需 Git、pnpm，也无需自行编译源代码。本地 AI 模型需要额外的硬件资源，具体要求取决于所选模型。

### 2. 打开安装程序

解压安装 ZIP，然后从解压后的文件夹中启动：

| 操作系统      | 启动方式                      |
| ------------- | ----------------------------- |
| Windows       | 双击 `START.cmd`              |
| macOS / Linux | 在终端运行 `sh START.command` |

打开终端显示的**私有本地链接**。选择语言、模型提供商、权限和工具包。安装向导会创建数据库，并检查工作空间是否就绪。

**请保留解压后的安装包和终端显示的安装目录。** 重新启动或继续未完成的安装时会用到它们。[重启、备份与服务器设置 →](./docs/self-hosting.md)

### 3. 明确交办第一项工作

创建一个项目，选择智能体，并描述你希望得到的结果。先从容易核实的任务开始：

> 比较 [主题] 的三个选项。使用一手来源，附上链接和日期，并保存一页比较报告。除非需要独立开展工作，否则继续使用同一个智能体。如果缺少必要信息，请向我询问。

对于定期工作，请同时说明执行间隔和每轮的完成条件：

> 每 24 小时检查一次 [公开网页] 是否发生有意义的变化。有变化时，保存带日期的摘要。完成每一轮后，等待下一个计划时间。不要联系任何人，也不要对外发布内容。

**一份有用的任务说明包括：** 输入信息、预期输出、核实方法，以及对操作或支出的限制。

## 认识各个页面

| 页面                     | 用途                                           |
| ------------------------ | ---------------------------------------------- |
| **首页**                 | 查看智能体、正在进行的工作和近期活动。         |
| **项目**                 | 集中管理任务说明、对话、委派工作、会议和结果。 |
| **专家与团队工作室**     | 调整智能体角色和模型，或从团队模板开始。       |
| **技能与工具**           | 浏览工作指南、查看工具要求并创建项目草稿。     |
| **审批**                 | 在执行前审阅需要你做决定的操作。               |
| **运行管理与运行检查器** | 查看执行记录、工具活动、中断和恢复情况。       |
| **公司聊天室**           | 与选定的智能体交谈，使用提及功能指定参与者。   |
| **设置**                 | 配置模型连接、语言、执行策略和源代码工作空间。 |

**技能（skill）** 是完成某项工作的指南。**工具** 执行具体操作，例如检查数据或使用浏览器。**智能体** 结合指令、模型和获准使用的工具处理任务。

## 实用工具，也支持扩展

内置库涵盖**研究、软件、数据、文档和日常运营**，包含工作指南、功能工具和运行时工具。智能体可以查找指南，并在需要时加载其中的指令。

- **加入自己的指南。** 创建、编辑、导入或导出个人技能和辅助工具预设。
- **添加可执行工具。** 在编辑器中定义 Node 工具；执行遵循配置的权限与审批规则。[工具编写指南 →](./docs/personal-programs.md)
- **处理源代码。** 连接 Git 仓库，让智能体在隔离副本中提出修改，检查差异并运行验证后再应用。部署是单独的步骤。[源代码工作流程 →](./docs/source-workspaces.md)

[浏览技能与工具指南 →](./docs/skills-and-tools.md)

## 按任务规模使用资源

常规任务从经济型模型路由开始。额外的工具定义按需加载。已有智能体可以复用，任务委派由服务器检查：默认情况下，每个任务族（含父任务）最多有**四个活动任务**。

父任务等待活动子任务时，不会调用模型。定期工作会在计划周期之间等待。用量检查涵盖执行调用和结果审查调用，既有每项任务或每轮的限制，也有定期工作的滚动每日额度。

**模型成本由你的选择决定。** 云端模型通过你自己的提供商账户计费；本地模型使用你的硬件。明确选择免费或本地模型时，系统不会暗中切换到付费模型。正在执行的请求可能使已记录用量超出限制，缺失的费用信息仍视为未知。需要控制账单上限时，请在提供商侧设置限制。

[模型路由、委派与预算设置 →](./docs/efficient-work.md)

## 你的工作空间，由你选择访问方式

在安装时或设置中选择**只读、需要审批、完全访问或自定义策略**。完全访问允许在已启用工具中执行更多操作；主机执行仍有独立的配置和控制。启用广泛的主机访问前，请阅读[安全模型](./docs/security-model.md)。

**在手机上：** 通过私有 HTTPS 连接打开同一个自适应界面。可选安装流程使用已有的 Tailscale 连接；文档也介绍了自行管理 VPN 的方式。主机必须保持在线。[手机访问指南 →](./docs/mobile-access.md)

**使用你的语言：** English · Türkçe · Deutsch · Русский · 简体中文 · 繁體中文 · العربية。阿拉伯语支持从右向左的布局。自定义指令、外部输出和历史记录保留原始文本。[翻译覆盖范围 →](./docs/localization.md)

> [!NOTE]
> 目前每次安装仅支持一名受信任的操作人员，不包含共享多用户账户或租户隔离。请保持远程访问私密，并使用 HTTPS 和操作人员身份验证保护访问。

## 已完成的验证

**0.2.0 版本**包含预构建 Linux amd64/arm64 镜像和引导式安装程序。记录的验收结果包括：

- **1,479 项源代码测试通过**，零失败，六项因环境条件跳过；PostgreSQL 并发检查单独运行。
- **922 项浏览器测试通过**，以及 Windows、Intel Mac 和 Apple Silicon Mac 检查。
- 实际容器安装与恢复安装、短时恢复和持续运行检查，以及使用真实模型对一项有限任务和两个定期周期进行的限定范围验证。
- 无需登录的安装包下载、校验和匹配，以及公开起始页在手机宽度下的七种语言检查。

这些结果仅对应所述版本。24 小时持续运行测试、实体手机和移动网络验收，以及母语使用者审校仍未完成。开放式任务可能需要你的补充信息或决定，无法保证每一种工作都能完成。
