# 連接模型，保留你的第一個任務

[English](./model-connections.md) · [Türkçe](./model-connections.tr.md) · [Deutsch](./model-connections.de.md) · [Русский](./model-connections.ru.md) · [简体中文](./model-connections.zh-CN.md) · [繁體中文](./model-connections.zh-TW.md) · [العربية](./model-connections.ar.md)

> 適用於 v0.4.0 及更新版本。較早的安裝套件不包含此流程。

## 先寫下你想要的結果

在首頁或新增專案頁面寫下任務，再開啟模型連線視窗。關閉視窗、取消登入或切換介面
語言都不會提交任務；只有你明確啟動時才會提交。若瀏覽器無法儲存草稿，警告會
說明重新載入頁面的限制。

| 選項     | 所需條件                                     | 儲存能確認什麼                                     |
| -------- | -------------------------------------------- | -------------------------------------------------- |
| 本機模型 | 已執行的 Ollama 服務及已安裝、支援工具的模型 | 位址與發現的模型；不下載模型，也不發送推論測試     |
| ChatGPT  | 符合條件的帳戶及模型使用授權                 | 已審核的註冊和獨立的帳戶選擇；可用性與配額仍需檢查 |
| API 金鑰 | 自己的 OpenAI 或 OpenRouter 金鑰             | 已儲存的設定；供應商可能收費                       |

Ollama 位址必須能被應用程式的**後端服務**存取。手機上的 `localhost` 指手機，容器內的
`localhost` 指容器。請填寫安裝環境能夠存取的私人位址。恢復安裝預設值會移除
已儲存的覆寫值；環境變數中的連線可能仍然生效。

## 啟動前確認狀態

任務開始時只傳送計算、完成任務和載入工具的結構定義。其他已授權工具，
包括指南、提問與核准請求，會在需要時載入完整定義。載入不會授予權限。
這會縮小首次請求，但某些流程需要額外呼叫模型。小型本機模型仍需透過
真實任務驗證。

發現模型、建立連線與完成測試是不同狀態。進階設定中的明確模型測試會發送請求，
儲存連線不會。先前已啟動、正在等待供應商的任務可能在儲存後繼續執行。
儲存結果尚未確認時，先查看目前狀態，不要直接重複儲存。

儲存 ChatGPT 帳戶與選擇該帳戶是兩個步驟。僅身分驗證授權不能執行模型。
伺服器或容器安裝請在自己的電腦上依照[受保護的轉移指南](./chatgpt-connection.md#on-a-server-or-in-a-container)
操作；手機無法存取伺服器的本機登入回呼。不要將憑證貼到瀏覽器介面。

返回任務，確認權限與預期輸出，再啟動。[手機私人存取](./mobile-access.md)使用同一個網頁介面。
可選的原生 Codex 程式碼執行器有[獨立的平台要求](./chatgpt-connection.md#optional-governed-coding-runtime)；
連接模型不會自動啟用它。

如果模型未回報權杖用量，工作及其子工作會在進一步呼叫前暫停，已有記錄
將保留。請檢查呼叫，並使用能夠回報用量的供應商建立新工作。即使權杖用量
報告完整，未回報的美元費用仍顯示為未知。

## 選用程式碼環境安裝

容器安裝精靈提供獨立、預設停用的 **Codex 程式碼工作程序** 選項。需要 Linux x64 引擎、Compose 2.24.4 或更新版本及終端機權限。選擇程式碼工具套件不會啟用此選項。安裝後連線至符合資格的帳戶；其他任務繼續使用所選供應商。使用 AppArmor 的主機需要管理員載入隨附的設定檔。請參閱[安裝要求](./self-hosting.md#optional-coding-workers)。

## 本機模型效率（開發分支）

使用工具時，支援思考的本機模型預設收到 `reasoning_effort: none`。API 呼叫端可明確設定 `localReasoningEffort`。不使用工具的聊天保留模型預設設定；雲端模型不會加入此參數。支援情況與結果取決於模型。共用的內部規則以簡明英語撰寫；所選語言及完整的在地化或自訂角色文字仍會保留。

## 完成檢查（開發分支）

完成檢查會將每項必要操作與目前任務週期的工具使用紀錄核對。正確答案不能取代要求執行的操作。除最近的紀錄外，檢查也會讀取整個週期內有數量上限的工具計數；截斷紀錄中沒有某項操作，並不能證明它從未發生。此流程使用現有的檢查呼叫。中繼資料和模型判斷不能保證檔案、測試或結果的品質。
