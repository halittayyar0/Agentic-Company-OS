Builtin help/usage/write/delete text, path-policy errors, emergency cancellation and host/sudo diagnostics use the selected catalog. The review reproduced split UTF-8 process corruption; incremental decoding is now implemented and awaiting the repair checkpoint.
- Existing filesystem exception classes/codes and legacy exception messages remain available; optional typed metadata localizes those errors at Terminal presentation boundaries. Approval hashes and emergency epochs are preserved. The review additionally reproduced missing inner file-lock revalidation in autonomous Terminal; the repair propagates a transaction-aware authority check without starting another effect or extending a lease.
- Help reflects the real external-process flag and explicitly describes host access and the required external container/VM isolation. It accurately states that Terminal rm/del delete directly; Files provides the separate version-reviewed flow. Autonomous rm/del retain their existing scoped approval requirement.
- The authenticated operator endpoint accepts an optional enum locale. Explicit locale is part of the durable request identity; omitted legacy requests retain their original `{command, as}` hash. Replays return original results, and the same ID with a changed or newly added locale conflicts. New Terminal activity summaries use the execution language.
- Version 2 browser intent records carry the submitted locale. Strict recovery parsing preserves version 1 and no-version records, rejects missing/invalid locale or locale smuggling into old versions, and compares locale as part of the original intent. Terminal sends the captured locale and includes it in recovery component identity.
- A reproduced founder-route defect previously returned 503 because its default directory resolved through invalid agent identity zero. The route now passes the actual reviewed agent's workspace path, retaining the existing effect guard and opt-in requirement. The controlled HTTP fixture verifies the resulting directory and output.
