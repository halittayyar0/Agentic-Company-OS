# 0.2.0 acceptance scope

This release targets one trusted operator on a private installation. The public
site distributes the software; it is not a shared hosted agent account.

## Required publication gates

- Source tests, generated API parity, types, build, dependency/license audit,
  browser suite, CodeQL and full-history secret scan for the release revision.
- Windows process and PostgreSQL runtime checks; native macOS Intel and Apple Silicon.
- Production container startup, real wizard installation/resume and the ten-minute
  fault-injected container endurance proof with its independent report verifier.
- Portable image installation/resume and artifact integrity verification.
- Actual provider-backed finite completion and two scheduled recurring cycles.

The exact-revision results are available in [GitHub Actions](https://github.com/halittayyar0/Agentic-Company-OS/actions).
Do not infer a passing gate from this checklist; release notes record observed results.

## Observed development evidence

Independent review identified and fixed three defects: provider review outages
classified as runtime bugs, missing review spend admission, and unknown cost
displayed as zero. Regression tests failed before each correction and passed after it.
Portable setup was checked in a real browser, and the seven-language public page
was checked at phone width including Arabic RTL and functional task copying.
Real production container installation and resume passed in CI.

Live free-model testing exposed truncated review responses. A 400-token ceiling
returned no verdict; bounded additional output room allowed a real finite task to
finish using the calculator, with 17,265 tokens and provider-reported cost zero.
The test used dots-studio/dots-3-note-preview:free and did not create extra agents
or delegated tasks. Model availability and rate limits can change.

The same real installation then completed two scheduled recurring cycles using
35,460 total tokens and provider-reported cost zero. Both task modes passed the
saved-result check for 391. The fixture cancelled the recurring responsibility
after its second cycle and stopped its isolated API, workers and PostgreSQL.

## Limits that remain

The final dependency review found GHSA-58mr-gqgx-xq4g in fast-uri 3.1.6.
The locked override was updated to 3.1.7. Four upstream unterminated-host
examples were accepted by the old version and rejected by the fixed version;
valid IPv6 parsing was retained. Production audit and license checks passed.

No 24-hour soak certification, physical-phone/carrier test, universal external
exactly-once delivery, native-speaker translation certification, multi-user tenancy,
or hardened host-shell isolation is claimed. Reported spend limits can overshoot
by an in-flight request, and unknown provider cost remains unknown. Provider-side
budgets are still needed for a billing ceiling. A small arithmetic acceptance test
does not establish that every open-ended job can finish without operator input.
