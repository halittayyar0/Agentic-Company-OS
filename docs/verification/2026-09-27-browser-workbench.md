# Browser workbench checkpoint — 2026-09-27

Goal 7 remains active. This checkpoint covers operator browser controls, their phone/language interface, admission checks and uncertain outcomes. It does not declare the entire application release-ready.

## Changes

- Seven selected-language packs cover the toolbar, address/text forms, ownership, polling, validation, unavailable storage, recovery and close confirmation. Native 16px inputs, 44px targets, semantic themes and Arabic RTL replace the fixed dark Turkish controls. Forms use the shared React Hook Form/Zod boundary and inline first-invalid focus.
- Explicit Take control creates/acquires the browser. Read-only image requests do not create sessions. Images are labeled as periodic snapshots with a receipt time. Failed or malformed images retain the last good image and disable input. Actual-size viewing allows phone users to pan remote content within a bounded scroll region.
- A native text composer accepts completed multilingual text and IME composition. The backend uses `insertText`, preserves Unicode and rejects invalid/oversized input without shortening it. The remote page may emit multiple input events for multiline text; this is distinct from repeated API dispatch. Native Tab leaves the image. Named remote-key/history/scroll buttons provide keyboard and phone access.
- One outstanding mutation prevents a failed request from draining a queued sequence of actions. Metadata is stored before dispatch without text, addresses or secret leases. Lost/malformed outcomes survive reload as an explicit hold; manual inspection clears it without replay. Drafts are kept in tab memory across SPA navigation and newer drafts survive late replies. These markers are not durable server receipts or cross-device recovery.
- Private control is not invalidated by an ordinary public lease renewal. Inactive/unmounted work cannot dispatch new effects; late takeover cleanup retains the captured lease. Close has an explicit confirmation and exact-lease requirement.
- API and worker effects check persisted emergency stop and local stop/resume epochs. Stale input cannot allocate a browser. Stale close credentials cannot close a later agent-owned session. Navigation and input effects report uncertain completion rather than safe failure when their effect boundary was crossed. Worker acknowledgements preserve unknown outcomes and unauthenticated result envelopes as `unknown` in command metadata.

See [Browser workbench contracts](../browser-workbench.md) and [phone access](../mobile-access.md). Design decisions apply the Apple skill's `toolbars.md` and `focus-and-selection.md` best practices to a web interface: readable grouped controls, explicit ownership, visible focus and an exit from the remote-image interaction.

## Remaining work and limits

Project detail/Studio, project chat, global/project Operations, additional API/provider messages and authored playbooks remain in Goal 7. Browser and Terminal operator requests still need durable, queryable server recovery. A local hold acknowledgement does not cancel a previous request, prove its outcome or prevent an already-dispatched effect from completing later.

The test-runner follow-up found that ordinary database imports could inherit and migrate an installation database. General test admission now rejects database targets, migration-directory overrides, native race-test flags and production/split-role environments before discovery or spawning test processes. Three focused tests passed, including the real runner against a loopback connection trap: zero connections, no test discovery and no connection-string disclosure. The existing dedicated PostgreSQL commands remain separate. Direct `node --test` invocations bypass the general preflight and require a clean shell or the specific test's explicit disposable target; this is documented in CONTRIBUTING. The final general suite passed: **795 tests, 790 passed, five skipped, zero failed**, in 515.7 seconds. Scripts type checking, repository formatting and `git diff --check` also passed. This follow-up changes test admission and documentation, not the production UI verified above. Evidence is in `%TEMP%/acos-test-isolation-red.log`, `acos-test-isolation-green.log`, `acos-test-isolation-root.log` and `acos-browser-isolation-format.log`.

The remote screenshot has no third-party accessibility tree. Physical-phone private HTTPS, Safari, native IME, assistive technology and native-speaker review remain unverified. Native PostgreSQL multi-process proof, Docker topology, POSIX filesystem behavior, live providers and a real 24-hour run are not established by these fixture/local tests. No software was installed, and nothing was committed or published.
