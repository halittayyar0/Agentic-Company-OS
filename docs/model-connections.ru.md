# Подключите модель, сохранив первое задание

[English](./model-connections.md) · [Türkçe](./model-connections.tr.md) · [Deutsch](./model-connections.de.md) · [Русский](./model-connections.ru.md) · [简体中文](./model-connections.zh-CN.md) · [繁體中文](./model-connections.zh-TW.md) · [العربية](./model-connections.ar.md)

> Для v0.4.0 и новее. В более ранних установочных пакетах этого сценария нет.

## Начните с нужного результата

Напишите задание на главной странице или в новом проекте и откройте подключение
модели. Закрытие окна, отмена входа и смена языка не отправляют задание.
Запуск выполняется только вашим явным действием. Если браузер не может сохранить
данные, предупреждение объяснит ограничения при перезагрузке.

| Вариант          | Что требуется                                                     | Что подтверждает сохранение                                                         |
| ---------------- | ----------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| Локальная модель | Сервер Ollama с установленной моделью, поддерживающей инструменты | Адрес и найденные модели; без скачивания и запроса к модели                         |
| ChatGPT          | Подходящий аккаунт и разрешение использовать модели               | Проверенная регистрация и отдельный выбор; доступность и квота проверяются отдельно |
| API-ключ         | Собственный ключ OpenAI или OpenRouter                            | Сохранённая конфигурация; поставщик может взимать плату                             |

Адрес Ollama должен быть доступен **серверу приложения**. `localhost` на телефоне
означает телефон, в контейнере — контейнер. Используйте доступный частный адрес.
Возврат к настройке установки удаляет сохранённое переопределение; подключение
из переменных окружения может остаться активным.

## Проверьте состояние перед запуском

В начале задания отправляются только схемы вычисления, завершения и загрузки
инструментов. Остальные разрешённые инструменты, включая инструкции, вопросы
и запросы одобрения, загружаются полностью по мере необходимости. Загрузка
не даёт разрешений. Первый запрос становится меньше; некоторым сценариям нужен
дополнительный вызов модели. Небольшие локальные модели всё ещё нужно проверять
на реальном задании.

Найденная, подключённая и проверенная модель — разные состояния. Явный тест в
расширенных настройках отправляет запрос; сохранение — нет. Ранее запущенные
задания, ожидающие поставщика, могут продолжиться после сохранения. Если результат
не подтверждён, сначала проверьте текущее состояние.

Сохранение аккаунта ChatGPT и его выбор — отдельные действия. Вход только для
подтверждения личности не разрешает запросы к моделям. Для сервера или контейнера
выполните [защищённую передачу](./chatgpt-connection.md#on-a-server-or-in-a-container)
со своего компьютера. Телефон не достигает локального обратного вызова на сервере.
Не вставляйте учётные данные в браузер.

Проверьте разрешения и ожидаемый результат, затем запустите задание.
[Приватный доступ с телефона](./mobile-access.md) использует тот же веб-интерфейс.
У необязательного нативного исполнителя Codex есть [отдельные требования к платформе](./chatgpt-connection.md#optional-governed-coding-runtime);
подключение модели не включает его автоматически.

Если модель не сообщает использование токенов, задача и её подзадачи
приостанавливаются до следующих вызовов. Записи сохраняются. Проверьте вызовы
и начните новую задачу с провайдером, который сообщает использование токенов.
Отсутствующая цена в долларах остаётся неизвестной даже при полном отчёте
об использовании токенов.

## Необязательная установка среды программирования

В установщике контейнера есть отдельный, по умолчанию выключенный вариант **Codex для задач программирования**. Нужны движок Linux x64, Compose 2.24.4 или новее и доступ к терминалу. Набор инструментов для кода не включает этот вариант. Подключите подходящий аккаунт после установки; другие задачи сохраняют выбранного провайдера. На сервере с AppArmor администратор должен загрузить прилагаемый профиль. См. [требования к установке](./self-hosting.md#optional-coding-workers).

## Эффективность локальных моделей (ветка разработки)

При работе с инструментами локальным моделям с поддержкой рассуждений по умолчанию передаётся `reasoning_effort: none`. В API можно явно задать `localReasoningEffort`. Чат без инструментов сохраняет настройки модели; облачным моделям этот параметр не добавляется. Поддержка и результат зависят от модели. Общие внутренние правила сокращены и написаны по-английски; выбранный язык и полный локализованный или пользовательский текст роли сохраняются.

## Проверка завершения (ветка разработки)

Проверка завершения сопоставляет каждое требуемое действие с записями использования инструментов в текущем цикле задачи. Правильный ответ не заменяет запрошенное действие. Помимо последних записей используются ограниченные счётчики за весь цикл; отсутствие действия в сокращённой выборке не доказывает, что его не было. Используется существующий вызов проверки. Метаданные и решение модели не гарантируют качество файлов, тестов или результатов.
