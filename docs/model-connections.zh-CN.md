# 连接模型，保留你的第一个任务

[English](./model-connections.md) · [Türkçe](./model-connections.tr.md) · [Deutsch](./model-connections.de.md) · [Русский](./model-connections.ru.md) · [简体中文](./model-connections.zh-CN.md) · [繁體中文](./model-connections.zh-TW.md) · [العربية](./model-connections.ar.md)

> 适用于 v0.4.0 及更高版本。较早的安装包不包含这个流程。

## 先写下你想要的结果

在主页或新建项目页面写下任务，再打开模型连接窗口。关闭窗口、取消登录或切换界面
语言都不会提交任务；只有你明确启动时才会提交。如果浏览器无法保存草稿，警告会
说明重新加载页面的限制。

| 选项     | 所需条件                                     | 保存能确认什么                                     |
| -------- | -------------------------------------------- | -------------------------------------------------- |
| 本地模型 | 已运行的 Ollama 服务及已安装、支持工具的模型 | 地址和发现的模型；不下载模型，也不发送推理测试     |
| ChatGPT  | 符合条件的账户及模型使用授权                 | 已审核的注册和单独的账户选择；可用性与配额仍需检查 |
| API 密钥 | 自己的 OpenAI 或 OpenRouter 密钥             | 已保存的配置；服务商可能收费                       |

Ollama 地址必须能被应用的**后端服务**访问。手机上的 `localhost` 指手机，容器里的
`localhost` 指容器。请填写安装环境能够访问的私有地址。恢复安装默认值会删除
已保存的覆盖值；环境变量中的连接可能仍然生效。

## 启动前确认状态

任务开始时只发送计算、完成任务和加载工具的结构定义。其他已授权工具，
包括指南、提问和审批请求，会在需要时加载完整定义。加载不会授予权限。
这会缩小首次请求，但某些流程需要额外调用模型。小型本地模型仍需通过
真实任务验证。

发现模型、建立连接和完成测试是不同状态。高级设置中的明确模型测试会发送请求，
保存连接不会。之前已经启动、正在等待服务商的任务可能在保存后继续执行。
保存结果未确认时，先查看当前状态，不要直接重复保存。

保存 ChatGPT 账户和选择该账户是两个步骤。仅身份验证授权不能运行模型。
服务器或容器安装请在自己的电脑上按照[受保护的转移指南](./chatgpt-connection.md#on-a-server-or-in-a-container)
操作；手机无法访问服务器的本地登录回调。不要把凭证粘贴到浏览器界面。

回到任务，确认权限和期望输出，再启动。[手机私有访问](./mobile-access.md)使用同一个网页界面。
可选的原生 Codex 编程执行器有[独立的平台要求](./chatgpt-connection.md#optional-governed-coding-runtime)；
连接模型不会自动启用它。

如果模型未报告令牌用量，任务及其子任务会在进一步调用前暂停，已有记录
将保留。请检查调用，并使用能够报告用量的提供商创建新任务。即使令牌用量
报告完整，未报告的美元费用仍显示为未知。

## 可选编程环境安装

容器安装向导提供独立、默认关闭的 **Codex 编程工作进程** 选项。需要 Linux x64 引擎、Compose 2.24.4 或更新版本以及终端权限。选择代码工具包不会启用该选项。安装后连接符合条件的账户；其他任务继续使用所选服务商。使用 AppArmor 的主机需要管理员加载随附的配置。请参阅[安装要求](./self-hosting.md#optional-coding-workers)。

## 本地模型效率（开发分支）

使用工具时，支持思考的本地模型默认收到 `reasoning_effort: none`。API 调用方可以显式设置 `localReasoningEffort`。不使用工具的聊天保留模型默认设置；云端模型不会增加此参数。支持情况和结果取决于模型。共用的内部规则以简明英语编写；所选语言及完整的本地化或自定义角色文本仍会保留。

## 完成检查（开发分支）

完成检查会将每项必需操作与当前任务周期的工具使用记录核对。正确答案不能替代要求执行的操作。除最近的记录外，检查还会读取整个周期内有数量上限的工具计数；截断记录中没有某项操作，并不能证明它从未发生。此过程使用现有的检查调用。元数据和模型判断不能保证文件、测试或结果的质量。
