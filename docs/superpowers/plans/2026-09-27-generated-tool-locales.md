> **For agentic workers:** Use `superpowers:executing-plans` inline, with one fresh review after the complete feature. Track observed tests and rulings here. Preserve the existing uncommitted work.

**Goal:** Complete selected-language app-authored output across every remaining tool and its execution/recovery flow.

**Architecture:** Domain-sized typed catalogs and explicit outcomes on the existing executor; immutable presentation locale outside authority identity. Extend only bounded presentation evidence when recovery requires it.

**Tech stack:** TypeScript, Node 24, pnpm 10, existing Drizzle/PGlite/PostgreSQL and Chromium fixtures. No new dependency.

**Spec:** [Language contract](../specs/2026-09-27-generated-tool-locales.md).

## Global constraints

- Seven locales: `tr/en/de/ru/zh-CN/zh-TW/ar`; omitted direct-call locale defaults to Turkish.
- Preserve source text, permission/approval checks, durable identities and output bounds. Explicit outcomes replace prose inference in changed paths.
- Use concurrency two for source tests. Do not edit imported sources or rebuild under live full runners.
- Preserve WIP on `codex/oss-operator-recovery`; no automatic commit/push/install/paid call.
- A completed domain is progress, not completion of this feature or Goal 7.

## Review focus

1. Malformed JSON field types must not coerce into filesystem/browser/team effects; each owning task adds actual executor no-effect cases.
2. Locale changes while queued or after a crash must not change authority or overwrite historical source; Tasks 1 and 4 add captured/recovery cases.
3. A localized denial must not become success through `empty()` prefix inference; each domain verifies explicit outcomes and unchanged state.
4. Nested placeholder text, Unicode and whitespace in paths, page data and operator notes must remain literal; Tasks 1–3 include original source fixtures.
5. Telemetry/finalization failures after an effect must remain uncertain, never invite automatic repetition; Task 4 exercises wrapper and recovery paths.
