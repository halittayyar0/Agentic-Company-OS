# Efficient Autonomy Implementation Plan

> Execute inline using superpowers:executing-plans. User authorized implementation and publication; no repeated design approval gates. One independent final review.

**Goal:** Reduce setup friction and unnecessary agent/model work while delivering bounded durable recurring execution and a public distribution surface.

**Architecture:** Extend existing scheduler, model selection, durable tool dispatch and setup. Preserve single-operator isolation per installation; publish a separate static entry page.

**Tech Stack:** TypeScript, PostgreSQL/PGlite, React, pnpm, Docker, GitHub Actions.

**Spec:** docs/superpowers/specs/2026-09-29-efficient-autonomy-design.md

## Global constraints

- Seven locales and Arabic RTL; preserve explicit model/free-only pins.
- No prompt-only budget/delegation enforcement; no fabricated cost or completion evidence.
- No unrelated root changes, credentials in Git, mandatory paid hosting or branch-protection bypass.

## Review focus

- Parallel delegations and recursive children cannot bypass family capacity.
- Continuous lifetime totals must not consume a new cycle's allowance; rolling limits survive restarts.
- Empty/malformed/unknown usage must not be advertised as zero spend.
- Economy routing must not override manual or free-only model choices.
- Public start page must never expose a shared powerful operator session.
