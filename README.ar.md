## مساحة لإنجاز العمل ومتابعته

كلّف وكيلاً بمهمة محددة، أو أسند إليه مسؤولية تتكرر وفق جدول زمني. يمكنه استخدام الأدوات التي تسمح بها، وحفظ النتائج، وطلب المعلومات الناقصة أو موافقتك عند الحاجة. ويمكنك من الواجهة نفسها متابعة العمل، ومراجعة ما حدث، وإيقاف التنفيذ.

كل تثبيت هو **مساحة عمل خاصة لمشغّل واحد** تعمل على حاسوبك أو خادمك. تختار مزوّد النموذج وتحتفظ ببيانات اعتمادك. الموقع العام نقطة بداية للتثبيت؛ أما مهامك فتُنفّذ في مساحة عملك الخاصة.

| ابدأ بمهمة واحدة                                | أو أسند مسؤولية متكررة                        |
| ----------------------------------------------- | --------------------------------------------- |
| قارن ثلاثة منتجات مع روابط للمصادر.             | افحص صفحة عامة يومياً وسجّل التغييرات المهمة. |
| افحص ملف CSV وأبلغ عن القيم الناقصة أو المكررة. | راجع تقريراً دورياً وفق جدول زمني.            |
| راجع مستودعاً واقترح تعديلاً خضع للاختبار.      | كرر قائمة فحص محددة واحتفظ بنتيجة كل دورة.    |

هذه أمثلة لطلبات وليست نتائج مضمونة. تعتمد النتائج على النموذج والأدوات المتاحة والصلاحيات والمعلومات التي تقدمها.

## البدء السريع

### 1. اختر طريقة التثبيت

|                    | حزمة حاويات جاهزة                                                                                                                 | تثبيت أصلي من الشيفرة المصدرية                                                            |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| **مناسب لمن يريد** | البدء بالتطبيق المبني مسبقاً                                                                                                      | العمل مباشرة مع الشيفرة وأدوات الجهاز المضيف                                              |
| **المتطلبات**      | Node.js 24 وDocker يعمل بمحرك Linux مع Compose v2                                                                                 | Git وNode.js 24 وإصدار pnpm المحدد في المشروع وPostgreSQL؛ وChromium لأدوات المتصفح       |
| **بناء التطبيق**   | تُنزّل صورة ذات إصدار مثبت تلقائياً                                                                                               | يُبنى على جهازك                                                                           |
| **ابدأ من هنا**    | [تنزيل ملف ZIP للتثبيت](https://github.com/halittayyar0/Agentic-Company-OS/releases/latest/download/Agentic-Company-OS-setup.zip) | [دليل التثبيت الأصلي](./docs/self-hosting.md#guided-installation-windows-linux-and-macos) |

تتضمن حزمة الحاويات PostgreSQL وChromium، ولا تحتاج إلى Git أو pnpm أو بناء الشيفرة المصدرية. تحتاج نماذج الذكاء الاصطناعي المحلية إلى موارد عتادية إضافية؛ وتختلف المتطلبات بحسب النموذج الذي تختاره.

### 2. افتح برنامج التثبيت

فك ضغط ملف ZIP، ثم ابدأ من المجلد المستخرج:

| نظامك         | ما ينبغي تشغيله                    |
| ------------- | ---------------------------------- |
| Windows       | انقر مرتين على `START.cmd`         |
| macOS / Linux | شغّل `sh START.command` في الطرفية |

افتح **الرابط المحلي الخاص** الظاهر في الطرفية. اختر اللغة ومزوّد النموذج والصلاحيات وحزم الأدوات. ينشئ المعالج قاعدة البيانات ويتحقق من جاهزية مساحة العمل.

**احتفظ بالحزمة المستخرجة وبمجلد التثبيت الذي يظهر في الطرفية.** ستحتاج إليهما لإعادة التشغيل أو استكمال التثبيت. [إعادة التشغيل والنسخ الاحتياطي وإعداد الخادم ←](./docs/self-hosting.md)

### 3. حدّد أول مهمة بوضوح

أنشئ مشروعاً، واختر وكيلاً، وصف النتيجة المطلوبة. ابدأ بعمل يسهل عليك التحقق منه:

> قارن ثلاثة خيارات بشأن [الموضوع]. استخدم مصادر أولية، وأدرج الروابط والتواريخ، واحفظ مقارنة من صفحة واحدة. استمر باستخدام وكيل واحد ما لم تكن هناك حاجة إلى أعمال مستقلة. اسألني إذا كانت معلومات أساسية ناقصة.

للعمل المتكرر، حدّد الفترة الزمنية وشرط اكتمال كل دورة:

> كل 24 ساعة، افحص [الصفحة العامة] بحثاً عن تغييرات مهمة. احفظ ملخصاً مؤرخاً عند حدوث تغيير. أكمل كل دورة وانتظر الموعد التالي. لا تتواصل مع أي شخص ولا تنشر محتوى خارجياً.

**يتضمن وصف المهمة المفيد:** المدخلات، والنتيجة المتوقعة، وطريقة التحقق منها، وأي حدود للإجراءات أو الإنفاق.

## التعرف على صفحات مساحة العمل

| الصفحة                      | استخدامها                                                                   |
| --------------------------- | --------------------------------------------------------------------------- |
| **الرئيسية**                | عرض الوكلاء والعمل الجاري والنشاط الأخير.                                   |
| **المشاريع**                | جمع وصف المهمة والمحادثات والعمل المفوّض والاجتماعات والنتائج في مكان واحد. |
| **الخبراء واستوديو الفريق** | تعديل أدوار الوكلاء واختيارات النماذج، أو البدء من قالب فريق.               |
| **المهارات والأدوات**       | تصفّح أدلة العمل وفحص متطلبات الأدوات وإنشاء مسودة مشروع.                   |
| **الموافقات**               | مراجعة الإجراءات التي تحتاج إلى قرارك قبل تنفيذها.                          |
| **العمليات وفاحص التشغيل**  | فحص سجلات التنفيذ ونشاط الأدوات والانقطاعات والاستعادة.                     |
| **غرفة الشركة**             | التحدث مع وكلاء محددين واستخدام الإشارات لمخاطبة مشاركين بعينهم.            |
| **الإعدادات**               | ضبط اتصالات النماذج واللغة وسياسة التنفيذ ومساحات عمل الشيفرة المصدرية.     |

**المهارة (skill)** دليل لتنفيذ عمل. **الأداة** تنفّذ إجراءً، مثل فحص البيانات أو استخدام المتصفح. أما **الوكيل** فيجمع التعليمات والنموذج والأدوات المسموح بها للعمل على المهمة.

## أدوات مفيدة وإمكانية للتوسع

تغطي المكتبة المدمجة **البحث والبرمجيات والبيانات والمستندات والعمليات**. وتضم أدلة عمل وأدوات للقدرات وأدوات للتنفيذ. يمكن للوكلاء اكتشاف الأدلة وتحميل تعليماتها عند الحاجة.

- **أضف إرشاداتك.** أنشئ المهارات الشخصية والإعدادات المسبقة للأدوات المساعدة وعدّلها واستوردها أو صدّرها.
- **أضف أدوات قابلة للتنفيذ.** عرّف أدوات Node من المحرر؛ ويخضع التنفيذ لقواعد الصلاحيات والموافقات التي تضبطها. [إنشاء الأدوات ←](./docs/personal-programs.md)
- **اعمل على الشيفرة المصدرية.** اربط مستودع Git، ودع الوكيل يقترح تعديلات في نسخة معزولة، ثم افحص الفروق وشغّل الاختبارات قبل تطبيقها. النشر خطوة منفصلة. [سير عمل الشيفرة المصدرية ←](./docs/source-workspaces.md)

[تصفّح دليل المهارات والأدوات ←](./docs/skills-and-tools.md)

## موارد تناسب حجم العمل

تبدأ المهام الروتينية بمسار اقتصادي لاختيار النموذج. تُحمّل تعريفات الأدوات الإضافية عند الطلب. يمكن إعادة استخدام الوكلاء الحاليين، ويتحقق الخادم من التفويض: الحد الافتراضي هو **أربع مهام نشطة لكل عائلة مهام**، بما فيها المهمة الأم.

المهمة الأم التي تنتظر مهام فرعية نشطة لا ترسل طلبات إلى النموذج. وينتظر العمل المتكرر بين الدورات المجدولة. تشمل مراجعة الاستخدام طلبات التنفيذ وطلبات مراجعة النتائج، مع حدود لكل مهمة أو دورة، وحصة يومية متحركة للعمل المتكرر.

**أنت تتحكم في تكلفة النماذج.** يحاسبك مزوّدو الخدمات السحابية من خلال حسابك لديهم؛ وتستخدم النماذج المحلية عتادك. عند اختيار نموذج مجاني أو محلي صراحةً، لا يحدث انتقال صامت إلى نموذج مدفوع. قد يتسبب طلب قيد التنفيذ في تجاوز حد الاستخدام المسجّل، وتظل التكلفة غير المبلّغ عنها مجهولة. استخدم حدود المزوّد لوضع سقف للفوترة.

[اختيار النماذج والتفويض وإعدادات الميزانية ←](./docs/efficient-work.md)

## مساحة عملك وخيارات الوصول الخاصة بك

اختر أثناء التثبيت أو من الإعدادات **القراءة فقط، أو الوصول بموافقة، أو الوصول الكامل، أو سياسة مخصصة**. يتيح الوصول الكامل إجراءات أوسع ضمن الأدوات المفعلة؛ ويظل التنفيذ على الجهاز المضيف خاضعاً لإعداداته وضوابطه الخاصة. راجع [نموذج الأمان](./docs/security-model.md) قبل تفعيل وصول واسع إلى الجهاز المضيف.

**على هاتفك:** افتح الواجهة المتجاوبة نفسها عبر HTTPS خاص. يستخدم مسار الإعداد الاختياري اتصال Tailscale موجوداً؛ كما توثّق الأدلة استخدام VPN تديره بنفسك. يجب أن يبقى الجهاز المضيف متصلاً. [دليل الوصول من الهاتف ←](./docs/mobile-access.md)

**بلغتك:** English · Türkçe · Deutsch · Русский · 简体中文 · 繁體中文 · العربية. تدعم العربية تخطيطاً من اليمين إلى اليسار. وتحتفظ تعليماتك المخصصة والمخرجات الخارجية والسجلات السابقة بنصوصها الأصلية. [نطاق الترجمة ←](./docs/localization.md)

> **ملاحظة:**
> يدعم التطبيق حالياً مشغّلاً واحداً موثوقاً لكل تثبيت. لا يتضمن حسابات مشتركة متعددة المستخدمين أو عزلاً بين المستأجرين. اجعل الوصول البعيد خاصاً واحمه باستخدام HTTPS ومصادقة المشغّل.

## ما تم التحقق منه

يتضمن **الإصدار 0.2.0** صورة Linux مبنية مسبقاً لمعمارية amd64/arm64 وبرنامج تثبيت موجّهاً. تشمل نتائج القبول المسجلة:

- **نجاح 1,479 اختباراً للشيفرة المصدرية**، دون إخفاقات، مع تخطي ستة اختبارات تعتمد على البيئة؛ وتُجرى اختبارات التزامن في PostgreSQL بصورة منفصلة.
- **نجاح 922 اختباراً للمتصفح**، إضافة إلى فحوص Windows وIntel Mac وApple Silicon Mac.
- تثبيتاً فعلياً للحاويات واستكمال التثبيت، وفحوصاً قصيرة للاستعادة واستمرار التشغيل، وتحققاً محدود النطاق بنموذج فعلي لمهمة محددة النهاية ودورتين من عمل متكرر.
- تنزيل الحزم دون تسجيل دخول، وتطابق مجاميع التحقق، وفحص صفحة البداية العامة باللغات السبع عند عرض يناسب الهاتف.

تخص هذه النتائج الإصدار المذكور. لا تزال تجربة التشغيل المستمر لمدة 24 ساعة، واختبارات القبول على هواتف فعلية وشبكات محمول، ومراجعة الترجمة من متحدثين أصليين غير مكتملة. قد تحتاج المهام المفتوحة إلى معلوماتك أو قرارك؛ ولا يُضمن إكمال كل عمل ممكن.
