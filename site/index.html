Know before you start.

        

          Each installation is a single-operator workspace. Cloud model charges
          belong to your provider account; set a hard spending cap there.
          Reported usage limits cannot cancel an already running provider
          request. Local models avoid per-token API charges but use your
          hardware. Use private HTTPS for phone access. No separate AgenticOS
          mobile app is needed.
