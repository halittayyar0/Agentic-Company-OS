## Рабочее пространство для выполнения задач

Поручите агенту конкретную задачу или задайте обязанность, повторяющуюся по расписанию. Он сможет использовать разрешённые инструменты, сохранять результаты и запрашивать недостающие сведения или ваше одобрение. В том же интерфейсе можно следить за работой, проверять выполненные действия и останавливать исполнение.

Каждая установка — это **личное рабочее пространство для одного оператора**, работающее на вашем компьютере или сервере. Вы выбираете поставщика модели и используете собственные учётные данные. Общедоступный сайт помогает начать установку; задачи выполняются в вашем рабочем пространстве.

| Начните с разовой задачи                                | Или поручите регулярную работу                                               |
| ------------------------------------------------------- | ---------------------------------------------------------------------------- |
| Сравнить три товара со ссылками на источники.           | Ежедневно проверять общедоступную страницу и фиксировать значимые изменения. |
| Найти пропуски и дубликаты в CSV-файле.                 | Проверять регулярный отчёт по расписанию.                                    |
| Изучить репозиторий и предложить проверенное изменение. | Повторять заданный список проверок и сохранять результат каждого цикла.      |

Это примеры поручений, а не гарантированные результаты. Результат зависит от модели, доступных инструментов, разрешений и предоставленной информации.

## Быстрый старт

### 1. Скачайте нативный пакет

На странице [выпусков](https://github.com/halittayyar0/Agentic-Company-OS/releases/latest) выберите актуальный установочный архив для своего компьютера, проверьте версию и контрольную сумму. Node.js, PostgreSQL и готовое приложение включены; отдельно устанавливать Node.js, Docker, pnpm, Git или PostgreSQL не требуется.

| Система             | Архив                                    |
| ------------------- | ---------------------------------------- |
| Windows x64         | `Agentic-Company-OS-win32-x64.zip`       |
| macOS Intel         | `Agentic-Company-OS-darwin-x64.tar.gz`   |
| macOS Apple Silicon | `Agentic-Company-OS-darwin-arm64.tar.gz` |
| Linux x64           | `Agentic-Company-OS-linux-x64.tar.gz`    |
| Linux ARM64         | `Agentic-Company-OS-linux-arm64.tar.gz`  |

Целевые системы: Windows 10 (1903+)/11 x64, macOS 15 на Intel/Apple Silicon и Ubuntu 24.04 на x64/ARM64. Linux-пакеты собраны на базе Ubuntu 24.04/glibc; более старые glibc и Alpine/musl не являются поддерживаемыми средами. Нативного пакета Windows ARM64 нет. Пакеты Windows/macOS не подписаны; нотариальное подтверждение macOS и репутация SmartScreen не предоставляются. Проверьте обычные предупреждения системы и контрольную сумму, не отключая защиту ОС.

### 2. Откройте рабочее пространство

Распакуйте **весь архив** в папку. В Windows дважды нажмите `START.cmd`. В macOS откройте `START.command` или выполните `./START.command` в терминале macOS/Linux. Храните файлы вместе. Программа запуска открывает приватную локальную ссылку в браузере и печатает её в терминале. Выберите один из семи языков, проверьте разрешения и подключите модель.

По умолчанию приложение слушает loopback (`127.0.0.1`). Оставьте терминал открытым; **Ctrl+C** останавливает приложение, рабочие процессы и частную базу данных. Без браузера: `START.cmd --no-browser` или `./START.command --no-browser`. Данные и ключи находятся в частной папке установки вне пакета. Сохраните её и исходный пакет: повторный запуск того же пакета в исходном расположении продолжает сохранённую установку. Перенос данных в другой пакет и обновления не автоматизированы; сохраните проверенную резервную копию и следуйте [руководству по обновлению](./docs/self-hosting.md#upgrades).

Веса моделей и доступ к провайдеру не включены. Для ИИ-задач нужна настроенная модель Ollama или рабочее подключение к провайдеру; облачный провайдер может взимать плату. Локальные вспомогательные проверки работают без платного провайдера.

Для первой локальной модели откройте **Подключить → Локальная модель**. Приложение
даёт ссылку на официальную инструкцию Ollama для ОС сервера модели. Запустите
Ollama 0.40.3 или новее, сохраните его частный адрес и нажмите **Скачать модель**.
Начальная модель занимает на этом сервере около 2 ГБ плюс временное место. После
проверки вернитесь к сохранённому черновику и выберите момент запуска. Уже
ожидающие эту модель задачи могут продолжиться.
[Загрузка, хранение и восстановление →](./docs/local-models.md#get-your-first-local-model)

Расширенные варианты: отдельный [пакет Docker](./docs/self-hosting.md#portable-container-installer) и [установка из исходного кода](./docs/self-hosting.md#source-installation-prerequisites) сохраняют собственные требования.

### 3. Чётко сформулируйте первую задачу

Создайте проект, выберите агента и опишите ожидаемый результат. Начните с работы, которую легко проверить:

> Сравни три варианта по теме [тема]. Используй первичные источники, добавь ссылки и даты, сохрани сравнение на одной странице. Продолжай с одним агентом, если независимая работа не требуется. Спроси меня, если не хватает обязательных сведений.

Для регулярной работы укажите и интервал, и критерий завершения каждого цикла:

> Каждые 24 часа проверяй [общедоступную страницу] на значимые изменения. При изменениях сохраняй сводку с датой. Завершай каждый цикл и жди следующего запуска по расписанию. Ни с кем не связывайся и ничего не публикуй вовне.

**Полезное описание задачи содержит:** исходные данные, ожидаемый результат, способ проверки и ограничения на действия или расходы.

Кнопка **Скачать сводку (.txt)** сохраняет готовую сводку в текстовый файл на вашем устройстве. В файл входят текущий статус проекта и отчёт агента. Скачивание не расходует токены модели. [Как сохранить итог работы →](./docs/delivery-summary.md)

## Как устроено рабочее пространство

| Раздел                            | Для чего нужен                                                                                   |
| --------------------------------- | ------------------------------------------------------------------------------------------------ |
| **Главная**                       | Смотреть агентов, текущую работу и последние действия.                                           |
| **Проекты**                       | Хранить вместе описание задачи, беседы, делегированную работу, встречи и результаты.             |
| **Эксперты и студия команды**     | Менять роли и модели агентов или начинать с шаблона команды.                                     |
| **Навыки и инструменты**          | Изучать рабочие руководства, проверять требования инструментов и создавать черновик проекта.     |
| **Одобрения**                     | Рассматривать действия, которым нужно ваше решение до выполнения.                                |
| **Операции и инспектор запусков** | Проверять записи исполнения, использование инструментов, прерывания и восстановление.            |
| **Комната компании**              | Общаться с выбранными агентами и обращаться к участникам через упоминания.                       |
| **Настройки**                     | Настраивать подключения моделей, язык, правила исполнения и рабочие пространства исходного кода. |

**Навык (skill)** — руководство по выполнению работы. **Инструмент** выполняет действие, например анализирует данные или управляет браузером. **Агент** использует инструкции, модель и разрешённые инструменты для решения задачи.

## Полезные инструменты и возможности расширения

Встроенная библиотека охватывает **исследования, программирование, данные, документы и операционную работу**. В неё входят рабочие руководства, инструменты отдельных возможностей и инструменты исполнения. Агенты могут находить руководства и загружать инструкции по мере необходимости.

- **Добавляйте свои инструкции.** Создавайте, редактируйте, импортируйте и экспортируйте личные навыки и шаблоны вспомогательных инструментов.
- **Добавляйте исполняемые инструменты.** Определяйте инструменты Node в редакторе; исполнение подчиняется настроенным правилам разрешений и одобрений. [Создание инструментов →](./docs/personal-programs.md)
- **Работайте с исходным кодом.** Подключите Git-репозиторий, поручите агенту подготовить изменения в изолированной копии, изучите различия и выполните проверки перед применением. Развёртывание — отдельный шаг. [Работа с исходным кодом →](./docs/source-workspaces.md)

[Руководство по навыкам и инструментам →](./docs/skills-and-tools.md)

## Ресурсы по размеру задачи

Типовые задачи начинаются с экономичного маршрута выбора модели. Определения дополнительных инструментов загружаются по запросу. Существующих агентов можно использовать повторно, а делегирование проверяет сервер: по умолчанию допускаются **четыре активные задачи в одном семействе**, включая родительскую.

Родительская задача, ожидающая активные дочерние задачи, не обращается к модели. Регулярная работа ждёт между запланированными циклами. Контроль использования учитывает вызовы исполнения и проверки результата: действуют лимиты на задачу или цикл и скользящий суточный лимит для регулярной работы.

**Вы управляете затратами на модели.** Облачные поставщики выставляют счёт вашему аккаунту, а локальные модели используют ваше оборудование. При явном выборе бесплатной или локальной модели скрытого перехода на платную не происходит. Уже выполняющийся запрос может привести к превышению учитываемого лимита; неизвестная стоимость остаётся неизвестной. Для ограничения счёта используйте лимиты на стороне поставщика.

[Выбор модели, делегирование и бюджет →](./docs/efficient-work.md)

## Ваше пространство и ваши правила доступа

При установке или в настройках выберите **только чтение, доступ с одобрением, полный доступ или собственную политику**. Полный доступ разрешает больше действий в активированных инструментах; исполнение на хосте по-прежнему имеет отдельные настройки и проверки. Перед широким доступом к хосту изучите [модель безопасности](./docs/security-model.md).

**На телефоне:** откройте тот же адаптивный интерфейс через приватное HTTPS-подключение. Необязательный вариант настройки использует существующее подключение Tailscale; также описан самостоятельно управляемый VPN. Хост должен оставаться онлайн. [Доступ с телефона →](./docs/mobile-access.md)

**На вашем языке:** English · Türkçe · Deutsch · Русский · 简体中文 · 繁體中文 · العربية. Для арабского поддерживается интерфейс справа налево. Ваши инструкции, внешние результаты и исторические записи сохраняют исходный текст. [Охват переводов →](./docs/localization.md)

> [!NOTE]
> Сейчас приложение рассчитано на одного доверенного оператора в каждой установке. Общие многопользовательские аккаунты и изоляция арендаторов не предусмотрены. Делайте удалённый доступ приватным и защищайте его HTTPS и аутентификацией оператора.

## Что проверено

**Выпуск 0.2.0** содержит готовый образ Linux amd64/arm64 и пошаговый установщик. Зафиксированные приёмочные результаты включают:

- **1 479 успешных тестов исходного кода**, ноль ошибок и шесть пропусков, зависящих от окружения; проверки конкурентного доступа PostgreSQL выполняются отдельно.
- **922 успешных браузерных теста**, а также проверки Windows, Intel Mac и Apple Silicon Mac.
- Реальную установку контейнера и продолжение установки, короткие проверки восстановления и длительной работы, ограниченную проверку с настоящей моделью для конечной задачи и двух регулярных циклов.
- Скачивание пакетов без авторизации, совпадение контрольных сумм и проверки общедоступной стартовой страницы на семи языках при ширине экрана телефона.

Эти результаты относятся к указанному выпуску. Непрерывный 24-часовой тест, приёмка на физических телефонах и мобильных сетях и вычитка носителями языков ещё не завершены. Задачи без чётких границ могут требовать вашего участия; завершение любой возможной работы не гарантируется.
